# 수업에서 쓰는 프롬프트

Codex에 그대로 붙여 넣는 문장입니다.

## 시작

```
AGENTS.md를 읽고 시작해줘. worksheet/작업물목록.md에 내 정보 적어뒀어.
```

## 막혔을 때

내용을 지어낼 때
```
내가 말한 것만 써줘. 모르는 건 나한테 물어봐.
```

문장이 너무 길거나 거창할 때
```
[항목 이름] 부분을 세 문장으로 줄여줘. 형용사 빼고.
```

프롬프트 원문이 없을 때
```
프롬프트 블록은 삭제해줘.
```

자리표시가 남았을 때
```
portfolio/index.html에 {{ 가 남아 있는지 찾아서, 남은 항목을 다시 물어봐줘.
```

한 줄 소개가 안 떠오를 때
```
내 작업물 보고 한 줄 소개 후보 세 개만 줘. 고르는 건 내가 할게.
```
