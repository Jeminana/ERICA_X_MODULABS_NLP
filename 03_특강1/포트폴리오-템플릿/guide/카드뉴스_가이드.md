# 카드뉴스 가이드

퍼스널 브랜딩 페이지를 만들었으면 같은 내용을 카드 5장으로 바꿔 인스타그램, 페이스북, 유튜브에 올립니다. 페이지는 찾아온 사람이 보는 곳이고, 카드뉴스는 내가 먼저 알리는 곳입니다.

## 레퍼런스 찾기 (먼저 5분)

1. Pinterest에서 「카드뉴스 디자인」, 「인스타그램 캐러셀」, 「portfolio carousel」처럼 검색합니다.
2. 마음에 드는 카드를 2~3장 골라 이미지로 저장해 `reference` 폴더에 넣습니다. 폴더에 넣기 어렵다면 Codex 대화창에 이미지를 붙여 넣어도 됩니다.
3. 무엇이 마음에 들었는지 한 줄로 적어 두면 Codex가 더 잘 따라 합니다. 예: "큰 제목 한 줄과 아래 작은 글씨, 배경은 한 가지 색"

레퍼런스는 분위기와 배치만 참고합니다. 다른 사람의 카드에 있는 사진, 로고, 문구는 가져오지 않습니다.

## 만들기 (10분)

1. Codex에게 이렇게 말합니다.

   ```
   reference 폴더의 레퍼런스를 참고해서, AGENTS.md의 카드뉴스 순서대로 내 퍼스널 브랜딩 페이지를 카드뉴스 5장으로 만들어줘. 인스타그램용 세로로.
   ```

2. `portfolio/cardnews/index.html`을 브라우저로 열어 확인합니다.
3. 고치고 싶으면 "2번 카드 문장을 더 짧게 해줘"처럼 말합니다.
4. 쇼츠나 릴스용 세로 카드가 필요하면 "쇼츠용으로도 만들어줘"라고 한 번 더 요청합니다. 쇼츠와 릴스는 영상으로 올리는 곳이라, 1080×1920 카드 이미지를 만든 뒤 영상으로 한 번 더 만들어야 게시할 수 있습니다(예: 카드를 몇 초씩 넘기는 영상). 만든 영상은 `video/` 폴더에 넣습니다.

## 다섯 장의 순서 (체크리스트5)

| 장 | 들어갈 것 |
|---|---|
| 1 | 표지: 학교, 학부, 이름과 한 줄 소개 |
| 2 | 문제: 누구의 어떤 문제를 해결하려 했나요 |
| 3 | 접근과 에이전트 설계: 어떻게 풀었나요 |
| 4 | 결과: 된 것과 안 된 것 |
| 5 | 배운 것, 그리고 퍼스널 브랜딩 페이지 주소 (배포 전이면 이름과 연락 채널) |

## 페이지에 카드뉴스 섹션 넣기 (한 번 더)

카드뉴스를 만들었으면 퍼스널 브랜딩 페이지에도 넣습니다. SNS에서 본 사람과 페이지에 찾아온 사람이 같은 내용을 보게 됩니다.

```
만든 카드뉴스를 portfolio/index.html에 카드뉴스 섹션으로 추가해줘. 대표 프로젝트 아래에.
```

- 카드를 PNG로 저장했다면 `portfolio/cardnews/` 폴더에 넣어 두면 페이지에 그대로 보입니다.
- 브라우저와 휴대폰 폭에서 한 번씩 열어 봅니다.

## 크기

| 올릴 곳 | 크기 | 비율 |
|---|---|---|
| 인스타그램 게시물(여러 장), 페이스북 | 1080×1350 | 세로 4:5 |
| 유튜브 쇼츠, 인스타그램 릴스 | 1080×1920 | 세로 9:16 (영상으로 만들어 올림) |

플랫폼이 안내하는 권장 크기는 바뀔 수 있습니다. 올리는 화면에서 잘리는 곳이 없는지 한 번 봅니다.

## 이미지로 저장하기

- 브라우저에서 카드를 한 장씩 화면 캡처합니다. (Mac: Shift+Command+4, Windows: Win+Shift+S)
- 또는 Codex에게 "카드마다 PNG로 저장해줘"라고 요청해 봅니다. 환경에 따라 안 될 수 있습니다.

## 올리기 전에 확인

- 이름 표기가 퍼스널 브랜딩 페이지와 똑같은가 (「한양대학교 ERICA ○○학부 이름」)
- 마지막 장에 퍼스널 브랜딩 페이지 주소가 있는가. 아직 배포 전이면 이름과 연락 채널(이메일이나 LinkedIn)을 넣고, 배포한 뒤 주소를 추가합니다. 게시글 본문에도 주소를 한 번 적습니다
- 팀 프로젝트라면 팀원 이름이나 얼굴은 허락을 받았는가
- 내 연락처나 학번처럼 공개하고 싶지 않은 정보가 들어가지 않았는가
- 카드에 쓴 숫자와 결과가 퍼스널 브랜딩 페이지와 같은가

게시는 각자 계정에서 직접 합니다.

## 같이 올리면 좋은 글 (예시 양식)

```
이번 학기에 만든 [대표 프로젝트 이름]을 정리했습니다.
[한 줄 소개]
자세한 과정은 퍼스널 브랜딩 페이지에 있어요: [퍼스널 브랜딩 페이지 주소]
```
