# 퍼스널 브랜딩 페이지 템플릿

채용 담당자가 내 이름을 검색하거나 AI에게 "이 사람 어떤 사람이야?"라고 물었을 때 도착할 페이지를 만듭니다. 이번 학기에 만든 것들을 한곳에 모으고, 그중 대표 프로젝트 하나를 자세히 펼칩니다. 구성은 정해져 있고, 디자인은 여러분 마음대로 바꿉니다.

페이지는 세 부분입니다.

- 프로필: 이름, 한 줄 소개, 관심 직무, 연락처, 다른 곳 링크
- 작업물: 이번 학기 프로젝트를 카드로
- 대표 프로젝트: 문제, 접근, 에이전트 설계, 결과, 배운 것

## 시작하기 (수업 중)

1. `worksheet/작업물목록.md`를 먼저 채웁니다 (1부).
2. 이 폴더를 Codex에서 엽니다.
3. Codex에게 이렇게 말합니다.

   ```
   AGENTS.md를 읽고 시작해줘. worksheet/작업물목록.md에 내 정보 적어뒀어.
   ```

4. Codex가 빠진 것을 하나씩 물어봅니다. 아는 대로 답하고, 모르는 건 모른다고 하세요. 지어내지 않습니다.
5. 끝나면 `portfolio/index.html`을 더블클릭해서 브라우저로 확인합니다.
6. 고치고 싶은 문장은 "프로필의 한 줄 소개를 이렇게 바꿔줘"처럼 말하면 됩니다.

## 공개하기 (링크 만들기)

수업에서는 강사가 Vercel로 올리는 과정을 보여 줍니다. 해 보고 싶으면 수업 뒤에 아래 순서로 합니다.

1. `portfolio` 폴더 안의 파일 이름은 영문 소문자, 숫자, 하이픈(-)을 권장합니다. 한글 파일 이름은 올린 뒤 열리지 않을 수 있습니다. 확장자(.html, .png)는 그대로 두고, 이름을 바꿨다면 HTML 안의 연결 경로도 함께 고칩니다. Codex에게 "portfolio 폴더 파일 이름을 영문으로 바꾸고 연결 경로도 같이 고쳐줘"라고 하면 됩니다.
2. https://vercel.com/drop 에 들어가 `portfolio` 폴더를 끌어다 놓습니다. 로그인하지 않아도 됩니다.
3. 잠시 뒤 주소가 나옵니다. 눌러서 열어 봅니다.
4. 로그인 없이 올린 주소는 시간이 지나면 사라지는 임시 주소입니다. 배포 성공 화면에 나오는 만료 시각을 확인하고, 계속 쓰려면 사라지기 전에 같은 화면에서 「Claim Project」를 눌러 무료 계정으로 옮깁니다. Claim 링크는 남에게 보내지 않습니다.
5. 정한 주소 하나를 자소서, 이력서, LinkedIn에 똑같이 넣고 `checklist/내정보_일치확인.md`를 봅니다.

## 카드뉴스 만들기

퍼스널 브랜딩 페이지를 다 만들었으면 같은 내용으로 SNS용 카드 5장을 만듭니다. 먼저 Pinterest에서 레퍼런스를 2~3장 골라 `reference`에 넣습니다. `guide/카드뉴스_가이드.md`를 봅니다.

## 자주 막히는 곳

- Codex가 사실을 지어내려 하면: "내가 말한 것만 써줘"
- 한 줄 소개가 안 떠오르면: "내 작업물 보고 한 줄 소개 후보 세 개만 줘. 고르는 건 내가 할게"
- 프롬프트 원문이 기억 안 나면: "프롬프트 블록 삭제해줘"
- 페이지가 깨져 보이면: "남은 {{ 자리표시 찾아서 다시 물어봐줘"
- 디자인을 망쳤으면: "방금 바꾼 디자인 되돌려줘"

## 디자인 바꾸기

내용을 다 채웠으면 디자인을 내 것으로 만듭니다. 강사가 나눠 주는 디자인 키트(리소스 목록, 디자인 요청 프롬프트, 디자인 고르기, 좋은 포트폴리오 예시)를 함께 봅니다.

1. Pinterest에서 마음에 드는 분위기를 몇 장 모은다
2. getdesign.md에서 비슷한 느낌의 DESIGN.md를 하나 골라 내려받는다
3. 내려받은 파일 이름을 `DESIGN.md`로 바꿔 `design/` 폴더에 넣는다
4. Codex에게 "DESIGN.md를 읽고 내 퍼스널 브랜딩 페이지에 적용해줘. 로고나 회사 이름은 가져오지 마"라고 말한다
5. 색이나 글꼴을 내 취향으로 한두 개 바꾼다

getdesign.md의 DESIGN.md는 무료로 내려받아 쓸 수 있지만 해당 회사의 공식 디자인은 아닙니다. 회사 로고, 이름, 사진은 쓰지 않습니다.

## 폴더 구성

```
AGENTS.md                              Codex가 따르는 진행 규칙
README.md                              이 안내 문서
portfolio/index.html                   완성될 퍼스널 브랜딩 페이지 (디자인은 자유)
worksheet/작업물목록.md                 1부 워크시트. Codex가 읽어 갑니다
checklist/내정보_일치확인.md            마무리 확인표, 수업 뒤 할 일
prompts/수업용_프롬프트.md              수업에서 쓰는 프롬프트 모음
guide/카드뉴스_가이드.md                퍼스널 브랜딩 페이지로 SNS용 카드뉴스 만들기
reference/                             Pinterest에서 고른 카드뉴스 레퍼런스를 넣는 곳
my-materials/                          (추가) 내 과제물, 발표자료, 캡처, 프롬프트
design/                                (추가) getdesign.md에서 받은 DESIGN.md
video/                                 (추가) 쇼츠, 릴스 영상
```
